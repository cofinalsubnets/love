what is this??

tower is a short roguelike game written using the love programming language.

love is a dynamic programming language where every value is a one-argument function. love is written in C, and includes a C compiler called moon, which is written in love. love targets a wide range of platforms, such as wasm.

inle is a bare-metal OS kernel written in C and love, which provides a single-user posix-like system. inle is running in the box above. lush is love's posix-compatible command shell, and acts as the main entry point to the love ecosystem of programs.

love is distributed as a single binary, which runs natively on linux, freebsd and netbsd. the binary may be invoked as love or lush, and includes a busybox-like set of tools, including cc, vi and make, as well as several love-specific programs.

the api is currently 🫨 unstable. to get a love repl in lush, type love. type names () at the repl to see a list of the default namespace.

for a nice example of idiomatic love code, try vi /proc/src/apps/rove/rove.l. for another cool demo, try typing doom.
