what is this??

tower is a roguelike interactive short story written in the love programming language. love is a dynamically typed functional language where every value is a one-argument function.

love is written in C, and includes a C compiler called moon, which is written in love. moon builds OS-agnostic (linux/freebsd/netbsd) statically linked binaries for amd64, arm64, riscv64, and also targets thumb32 and wasm. love has been ported to several embedded platforms such as teensy 4.1, rp2040, and the playdate handheld game console. love and moon have no dependency on any other toolchain, such as gcc or llvm.

inle is a bare-metal OS kernel written in C and love, which provides a single-user posix-style system. inle is the OS running in the box on this page.

lush is love's posix-like command shell, and acts as the main entry point to the love ecosystem. love is distributed via the lush binary, which runs natively on linux, freebsd or netbsd, and includes a busybox-like set of default tools, including cc, vi and make, as well as many love-specific programs, including love and tower; lux, an X11 window manager; and sb, an experimental patch-based version control system.

the love/lush binary carries a compressed copy of its own source, which lets love rebuild itself deterministically from one command on any platform it supports. this can optionally be bootstrapped through the local C compiler (see love seed -h for details). love seed x64 (or a64) in the lush shell on this page will build a targeted binary in the browser you can then download and run on linux/freebsd/netbsd. running love web from that binary will build and serve this page.

the api is currently 🫨 unstable. to get a love repl in lush, type love. type names () at the repl to see a list of the default namespace.
